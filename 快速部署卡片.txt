┌───────────────────────────────────────────────────────────────┐
│ 第一步：本地打包（Windows）                                   │
└───────────────────────────────────────────────────────────────┘

1. 进入项目目录：
   cd D:\LibraryManagement

2. 执行打包脚本：
   .\build-images.bat

3. 等待完成（约15-25分钟），会生成：
   ✓ library-backend-v1.0.tar   (~1.5 GB)
   ✓ library-frontend-v1.0.tar  (~150 MB)

┌───────────────────────────────────────────────────────────────┐
│ 第二步：上传到服务器                                          │
└───────────────────────────────────────────────────────────────┘

需要上传的文件：
  □ library-backend-v1.0.tar
  □ library-frontend-v1.0.tar
  □ docker-compose-offline.yml
  □ deploy-server.sh

上传到服务器路径：/root/library-management/

┌───────────────────────────────────────────────────────────────┐
│ 第三步：服务器部署（Ubuntu 22.04）                            │
└───────────────────────────────────────────────────────────────┘

1. 准备MySQL数据库：
   mysql -u root -p
   
   CREATE DATABASE library_management 
     CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   
   CREATE USER 'library_user'@'%' IDENTIFIED BY 'library_pass';
   GRANT ALL PRIVILEGES ON library_management.* TO 'library_user'@'%';
   FLUSH PRIVILEGES;
   EXIT;

2. 执行部署：
   cd /root/library-management
   chmod +x deploy-server.sh
   sudo ./deploy-server.sh

3. 等待完成（约5分钟）

┌───────────────────────────────────────────────────────────────┐
│ 故障排查                                                      │
└───────────────────────────────────────────────────────────────┘

问题1：后端无法连接MySQL
解决：检查MySQL是否运行，检查用户权限
  sudo systemctl status mysql
  mysql -u library_user -p

问题2：端口被占用
解决：查看端口占用情况
  sudo netstat -tlnp | grep :80
  sudo netstat -tlnp | grep :8080

问题3：容器无法启动
解决：查看详细日志
  docker logs library-backend
  docker logs library-frontend

问题4：防火墙阻止访问
解决：开放端口
  sudo ufw allow 80/tcp
  sudo ufw allow 8080/tcp
