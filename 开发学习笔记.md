<h2>登录模块</h2>

```
流程图：
📊 完整的登录认证流程：
┌─────────────────────────────────────────────────────────┐
│                    第一步：登录                          │
└─────────────────────────────────────────────────────────┘

前端                                 后端
  │                                   │
  │  POST /api/auth/login             │
  │  { username, password } ─────────>│
  │                                   │
  │                        验证用户名密码 ✅
  │                                   │
  │                        生成 Token：
  │                        jwtUtil.generateToken(
  │                          "admin", 123, "admin"
  │                        )
  │                                   │
  │  <───────────── { token: "eyJ..." }
  │                                   │
localStorage.setItem('token', token)  │
  │                                   │

┌─────────────────────────────────────────────────────────┐
│                 第二步：访问需要登录的接口                │
└─────────────────────────────────────────────────────────┘

前端                                 后端
  │                                   │
  │  GET /api/books/my-borrowed      │
  │  Authorization: Bearer eyJ... ───>│
  │                                   │
  │                          拦截器 preHandle()
  │                                   │
  │                          1. 提取 Token ✅
  │                          2. 验证签名 ✅
  │                          3. 检查过期 ✅
  │                          4. 提取 userId ✅
  │                          5. 放行 return true
  │                                   │
  │                          Controller 执行
  │                          获取 userId = 123
  │                          查询该用户的借阅记录
  │                                   │
  │  <──────────────── { code: 200, data: [...] }
  │                                   │
```

```
请求流动
## 📊 **完整的请求流程图：**
┌────────────┐
│   前端      │
└─────┬──────┘
      │ axios.get('/api/books/my-borrowed')
      │ Headers: Authorization: Bearer eyJ...
      ↓
┌────────────────────────────────────────┐
│           Spring Boot 后端              │
├────────────────────────────────────────┤
│  1. Tomcat 接收请求                     │
│     ↓                                  │
│  2. DispatcherServlet                  │
│     ↓                                  │
│  3. 检查拦截器配置                      │
│     WebMvcConfig.addInterceptors()    │
│     ↓                                  │
│  4. 执行拦截器                          │
│     JwtAuthenticationInterceptor      │
│     .preHandle()                      │
│     ├─ 提取 Token                      │
│     ├─ 验证 Token                      │
│     └─ 返回 true/false                 │
│     ↓                                  │
│  5. 如果返回 true                       │
│     执行 Controller                    │
│     @GetMapping("/api/books/my-borrowed")│
│     ↓                                  │
│  6. 返回响应                            │
└────────────────────────────────────────┘
      ↓
┌────────────┐
│   前端      │
│ 收到响应     │
│ - 200: 正常  │
│ - 401: 跳转登录 │
└────────────┘
```
