# 📚 图书馆问题图书管理系统 - 完整启动教程


## 一、环境要求

### 必需软件

| 软件 | 版本要求 | 下载地址 |
|------|---------|----------|
| **JDK** | 21+ | [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) 或 [OpenJDK](https://adoptium.net/) |
| **Node.js** | 18+ | [Node.js 官网](https://nodejs.org/) |
| **MySQL** | 8.0+ | [MySQL 官网](https://dev.mysql.com/downloads/mysql/) |
| **Maven** | 3.6+ | 项目已内置 Maven Wrapper，无需单独安装 |

### 环境验证

打开命令行（Windows PowerShell 或 CMD），执行以下命令验证环境：

```powershell
# 验证 Java 版本（需要 21+）
java -version

# 验证 Node.js 版本（需要 18+）
node -v

# 验证 npm 版本
npm -v

# 验证 MySQL 是否安装
mysql --version
```


## 二、数据库配置

### 步骤 1：启动 MySQL 服务

**Windows：**
```powershell
# 检查 MySQL 服务状态
sc query mysql80

# 启动 MySQL 服务（如果未启动）
net start mysql80
```

### 步骤 2：执行数据库初始化脚本（MySQL Command Line）

打开 **MySQL 8.0 Command Line Client**（从开始菜单搜索），输入 root 密码后依次执行：

```sql
-- 1. 执行建表脚本（创建数据库和表结构）
source D:/LibraryManagement/Readme/01_mysql_schema.sql;

-- 2. 执行数据填充脚本（填充初始数据）
source D:/LibraryManagement/Readme/02_mysql_init_data.sql;
```

### 步骤 3：验证数据库创建成功

在 MySQL Command Line 中继续执行：

```sql
-- 查看数据库是否创建成功
SHOW DATABASES;

-- 选择数据库
USE library_management;

-- 查看所有表（应该有 9 张表）
SHOW TABLES;

-- 验证用户数据（应该有 3 个用户）
SELECT user_id, username, real_name, role FROM sys_user;
```

预期结果：
- 9 张数据表
- 3 个用户（admin、testuser、librarian）

### 步骤 4：配置后端数据库连接

编辑 `library-management-backend/src/main/resources/application-mysql.yml`：

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/library_management?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root                    # 👈 你的 MySQL 用户名
    password: your_password           # 👈 你的 MySQL 密码
```

## 三、后端启动

```powershell
# 进入后端项目目录
cd D:\LibraryManagement\library-management-backend

# 1. 首次运行：构建项目
.\build.bat

# 2. 启动应用
.\run.bat
```

|------|------|

| http://localhost:8080/api/doc.html | Swagger API 文档 |
| http://localhost:8080/api/v3/api-docs | OpenAPI JSON |

## 四、前端启动

### 步骤 1：安装依赖

```powershell
# 进入前端项目目录
cd D:\LibraryManagement\library-management-frontend

# 安装 Node.js 依赖
npm install
```

### 步骤 2：启动开发服务器

```powershell
npm run dev
```
